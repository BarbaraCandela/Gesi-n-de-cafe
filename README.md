Gestión de Café 

El objetivo es modelar la estructura básica de un café mediante distintas
clases y roles, aplicando conceptos de herencia y organización del código.

## Conceptos trabajados
- Programación orientada a objetos
- Clases y atributos
- Herencia (Empleado / Gerente)
- Organización del dominio del problema
- Separación de responsabilidades

## Tecnologías
- Java
- Programación orientada a objetos
